# Measured numbers used in the paper

Copied from the project reports. Nothing in these tables was re-estimated.

Sources:

- Balanced 1,442-clip hold-out and 75 external recordings: `Shoot_Catcher/docs/TEST_OBSERVATIONS_REPORT.md`
- 300-clip virtual Raspberry Pi, latency, PCEN distortion, ensemble: `FINAL_RESEARCH_BENCHMARK_REPORT.md` and `Shoot_Catcher/research_paper/jeevant_Words.md`
- Edge Impulse: the experiment table in `jeevant_Words.md`

Hardware note from those reports: latency is a virtual Raspberry Pi 4, four vCPUs, execution cap about 45-50%, 2 GB RAM. No physical Pi or Arduino was flashed for these numbers.
